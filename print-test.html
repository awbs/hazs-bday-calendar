Print test sheet

  1. Print this on plain paper with exactly the settings you'll use for the cards: Chrome, A4, Scale 100%, Margins None, Background graphics on, two-sided, flip on long edge.
  2. Check the 50 mm line in box 5 really measures 50 mm. If not, the printer is scaling: fix that first.
  3. Hold the sheet up to a window. The crosses in each box should sit on top of each other front and back.
  4. With a ruler, measure from each paper edge to the outer black line, on both sides, and type them below.
Measurements (mm) Should be 10.5 left and right, 16.5 top and bottom.
